# Fonts

These files are served by the site itself (see `app/fonts.ts`), so building the site never needs to reach Google Fonts.

| Files | Typeface | Used for | Licence |
|---|---|---|---|
| `inter-*.woff2` | Inter (Latin subset, variable weight) | English running text | SIL Open Font License 1.1 |
| `bricolage-*.woff2` | Bricolage Grotesque (Latin subset, weights 600 to 800) | English headings | SIL Open Font License 1.1 |
| `alexandria-*.woff2` | Alexandria (Arabic subset, weights 600 to 800) | Arabic headings | SIL Open Font License 1.1 |
| `plex-arabic-*.woff2` | IBM Plex Sans Arabic (Arabic subset) | Arabic running text | SIL Open Font License 1.1 |
| `plex-serif-*.woff2` | IBM Plex Serif (Latin subset) | Article body | SIL Open Font License 1.1 |
| `plex-mono-*.woff2` | IBM Plex Mono (Latin subset) | Code | SIL Open Font License 1.1 |

They were downloaded from Google Fonts on 2026-11-20.
